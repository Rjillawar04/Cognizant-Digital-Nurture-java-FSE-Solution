1. angular.json
Configuration file for the Angular project.

2. tsconfig.json
Main TypeScript configuration file.

3. tsconfig.app.json
TypeScript configuration for the Angular application.

4. package.json
Contains project information, scripts and dependencies.

5. src/main.ts
Entry point of the Angular application.

6. src/app/app.config.ts
Configures the Angular application using the standalone API.

7. src/app/app.ts
Root component of the application.

8. src/index.html
Main HTML page loaded in the browser.

maximumWarning
Shows a warning when the application size exceeds the specified limit.

maximumError
Stops the production build if the application size exceeds the specified limit.
